Next: CDQ Duplicate Matching Steps 4 & 5

Once you download the CVI file, follow these steps in CDQ to run the deduplication check.

1
Upload CVI to CDQ Data Mirror ManagementGo to CDQ → Data Mirror Management → Upload using General Mapping. Ensure NULL values are included where applicable.
2
Configure Duplicate MatchingGo to Duplicate Matching → Upload Configuration File. Adjust fuzzy matching threshold values if needed.
3
Select matching modeSelf-match: select one data source. Cross-system (e.g. PMD vs P08): select Pattern + Candidate sources.
4
US data ruleIf data includes US records, remove Tax Number 1–5 columns from the upload template before running.
5
Download results → Duplicate ConsolidationAlways select Duplicate Consolidation as the download option. Validate results and block or delete confirmed duplicate Vendors/Customers before migration.
